# Práctica integradora

## Desarrollo de la aplicación web "Bandera de México"

### Prompt 1

Actúa como un desarrollador web front-end experto. Necesito que me generes el código completo para una aplicación web interactiva titulada "Bandera de México", dividida estrictamente en tres archivos por separado: index.html, style.css y script.js.

La interfaz debe replicar exactamente el siguiente diseño y distribución visual:

- Título principal centrado en la parte superior: "Bandera de México".
- Un diseño horizontal de tres columnas principales que simulan las franjas de la bandera.
- Columna izquierda verde.
- Columna central blanca con el escudo de México.
- Columna derecha roja.
- Controles deslizantes para modificar los colores.
- Información de los integrantes.

### Prompt 2

La imagen del escudo de México no se muestra correctamente. Tengo descargada la imagen en mi computadora con el nombre "bandera". ¿Cómo puedo agregarla al código para que funcione con Live Server?

### Prompt 3

Mi imagen es de formato .jpg. Proporcióname todo el código completo de los tres archivos con el cambio correspondiente para utilizar bandera.jpg.
